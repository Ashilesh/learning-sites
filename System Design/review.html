📏 Rules of thumb

  • Quorum: R + W > N → reads see latest writes
  • 80/20: cache the hot 20%
  • Watch p99, not averages
  • Partition happens → pick C or A (CAP)
  • Else → pick latency or consistency (PACELC)

🧱 Go-to building blocks

  • Slow reads → cache / replica / CDN
  • Slow work → queue + workers
  • Too much data → shard
  • Too much traffic → LB + stateless servers
  • Live updates → WebSockets / SSE
  • Big files → object storage + CDN

🛡️ Reliability kit

  • Timeouts everywhere
  • Retries + backoff + jitter
  • Idempotency keys
  • Circuit breakers, bulkheads
  • Rate limits, load shedding
  • Multi-AZ, backups (tested!)
