🗣️Client & Server: asking and answering

The internet is mostly questions and answers. Your phone (the client) sends a request. A computer far away (the server) sends back a response.

👶 Like you're 5

A server is just a computer without a screen that sits in a big building (a data center) and waits all day for questions. It never sleeps! 😴❌

Thousands of servers live in racks in a data center, with huge power supplies, cooling and fat internet cables.

2.3

🌐Networking 101 in pictures

🏠 IP address

A computer's home address on the internet, like 142.250.80.46. DNS turns names into these.

🚪 Port

The apartment number at that address. Web = 443 (HTTPS), databases often 5432.

📦 Packets

Big messages are chopped into small envelopes that travel separately and get put back together.

🔒 HTTPS

HTTP inside a sealed envelope (TLS encryption) so nobody on the way can read or change it.

TCP vs UDP 📞 vs 📢

TCP 📞UDP 📢
Like…A phone call: “Can you hear me?” “Yes!”Shouting across a playground
DeliveryGuaranteed, in orderBest effort, may lose some
SpeedA bit slower (handshakes, re-sends)Very fast, no waiting
Used forWeb pages, APIs, email, filesVideo calls, games, live streams, DNS

Newer: QUIC / HTTP/3 runs on UDP but adds TCP-like reliability — faster connection setup, especially on mobile.

2.4

🔌APIs: how programs talk to each other

An API is a menu: a list of things you're allowed to ask a service for, and exactly how to ask.

🍽️ REST

A fixed menu of dishes at addresses (URLs). Uses HTTP verbs: GET read, POST create, PUT/PATCH update, DELETE.

Most common. Simple, cacheable, works everywhere.

🥗 GraphQL

A build-your-own-plate counter: the client asks for exactly the fields it wants, from many things, in one trip.

Great for mobile apps & complex screens. Harder to cache.

📟 gRPC

Walkie-talkies between kitchens: tiny binary messages (Protocol Buffers), super fast, strict contracts, streaming.

Best for service-to-service calls inside a company.

🍕 A REST API for a pizza shop

GET/pizzaslist the menu
GET/pizzas/42one pizza
POST/ordersplace an order
PATCH/orders/7change toppings
DELETE/orders/7cancel
GET/orders?status=baking&page=2filter + paginate
🧠 Good API habits
  • Nouns in URLs, verbs in methods
  • Paginate big lists (cursor > page numbers)
  • Version it: /v1/orders
  • Make retries safe with an idempotency key
  • Return clear errors & status codes

🕴️Forward proxy vs Reverse proxy

Forward proxy = your assistant. Websites see the proxy, not you.

Reverse proxy = the company's receptionist. You never see the servers behind it.

🧠 Why reverse proxies are everywhere

They hide internal servers, terminate HTTPS, compress, cache, block attacks, and load-balance. NGINX, Envoy and HAProxy are popular ones. A load balancer is basically a smart reverse proxy!
