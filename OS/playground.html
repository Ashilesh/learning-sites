📋 Cheat sheet

🧭 Moving around

  • pwd — where am I?
  • ls -la — what's here (all + details)
  • cd /etc — go somewhere
  • cd .. — up one · cd ~ — home
  • tree — draw the tree

📄 Files

  • cat f — show a file
  • touch f · mkdir d — create
  • rm f · rmdir d — remove
  • echo hi > f — write · >> append
  • stat f · chmod 755 f

🔍 Finding

  • grep word f — lines with "word"
  • head -n 3 f · tail f
  • wc -l f — count lines
  • sort — sort lines
  • which ls — where's a program?

🏃 Processes

  • ps aux · top
  • kill PID
  • uptime

🧮 System

  • free -h · df -h · lsblk
  • uname -a · neofetch
  • cat /proc/cpuinfo

🧩 Combine

  • ls /dev | grep tty
  • cat /etc/passwd | wc -l
  • ps | sort
  • history
⚠️ On a REAL Linux machine

Be careful with rm (there's no recycle bin!) and especially with sudo. Never run commands you don't understand, especially ones copied from strangers on the internet.
