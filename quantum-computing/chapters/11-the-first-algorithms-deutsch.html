11The First Algorithms: Deutsch, Deutsch-Jozsa, Bernstein-Vazirani and Simon

⏱ 4 min4 sections🟡 Student🔵 Developer✅ Completed

The hookA black box hides a secret string. A classical computer needs n questions. A quantum computer needs exactly one. Watch.

⚡ In 30 seconds (no jargon, promise)

These algorithms are puzzles about a mystery machine (an 'oracle'). Is it constant or balanced? What secret string is it hiding? Classically you have to poke it many times. Quantumly you feed it a superposition of every input once, and interference reveals the global answer directly. The problems are artificial, but they were the first proofs that quantum can beat classical at all.

These algorithms solve artificial problems, but each was a milestone proving that quantum computers can beat classical ones at all. They're also perfect for learning, because they're small enough to calculate by hand.

11.1Deutsch's algorithm (1985)

Problem: A function f takes one bit and returns one bit. There are four possible such functions:

Functionf(0)f(1)Type
f₁00Constant
f₂11Constant
f₃01Balanced
f₄10Balanced

Is f constant (same output for both inputs) or balanced (different outputs)?

  • Classically: you must compute both f(0) and f(1), which takes 2 queries.
  • Quantum: 1 query suffices.
✏️ Show the original text sketch
q0: |0⟩ ──H──┤    ├──H──M     → 0 means constant, 1 means balanced
             │ U_f│
q1: |1⟩ ──H──┤    ├─────
🧮 Pencil & paper

Worked example:

  1. After the first Hadamards: |+⟩|−⟩.
  2. The oracle with phase kickback gives (1/√2)[(−1)^f(0)|0⟩ + (−1)^f(1)|1⟩] ⊗ |−⟩.
  3. If f is constant, the two signs are equal, so q0 is ±|+⟩, and H turns it into |0⟩.
    If f is balanced, the signs differ, so q0 is ±|−⟩, and H turns it into |1⟩.
  4. Measure q0: 0 means constant, 1 means balanced, with certainty.

The algorithm learns a global property (f(0) ⊕ f(1)) without learning either value individually.

11.2The Deutsch-Jozsa algorithm (1992)

The same idea for an n-bit input, with the promise that f is either constant or balanced (outputs 0 for exactly half the inputs).

  • Classical deterministic: in the worst case you need 2ⁿ⁻¹ + 1 queries (just over half the inputs).
  • Quantum: 1 query. Apply H to all n qubits, query, apply H again, measure. All zeros means constant; anything else means balanced.

Why it works: the final amplitude of |00…0⟩ is (1/2ⁿ) Σₓ (−1)^f(x). That's ±1 if f is constant and exactly 0 if it's balanced.

⚠️ Heads up

Caveat: a randomised classical algorithm can solve this with high confidence using just a handful of queries. So Deutsch–Jozsa isn't a practical speedup; it's a proof of concept.

🤓 Did you know?

For the secret 101, the sign pattern after the oracle is exactly the product state |−⟩|+⟩|−⟩.

11.3The Bernstein-Vazirani algorithm (1993)

Problem: f(x) = s · x (mod 2), a bitwise dot product with a hidden string s. Find s.

  • Classical: query 100…0, 010…0, and so on. That's n queries, one per bit.
  • Quantum: 1 query, same circuit as Deutsch–Jozsa.
🧮 Pencil & paper

Worked example: hidden string s = 101 (3 qubits).
After the Hadamards and the oracle (with phase kickback), each basis state |x⟩ picks up the sign (−1)^(s·x), where s·x = x₁ + x₃ (mod 2):

xs·xSign
0000+
0011−
0100+
0111−
1001−
1010+
1101−
1110+

This pattern of signs is exactly the product state |−⟩|+⟩|−⟩. Applying H to each qubit gives |1⟩|0⟩|1⟩. Measure and read 101. Found in one query. ✓

11.4Simon's algorithm (1994)

Problem: f maps n-bit strings to n-bit strings, with a hidden "secret" s such that f(x) = f(y) exactly when y = x ⊕ s. Find s.

  • Classical: you need to find a collision f(x) = f(y), which takes about 2^(n/2) queries (exponential).
  • Quantum: about n queries plus some classical linear algebra (polynomial).

How it works: each run of the quantum circuit outputs a random string y satisfying y · s = 0 (mod 2). Collect about n such equations and solve them.

🧮 Pencil & paper

Worked example: n = 3, secret s = 110.
The valid outputs y are those with y₁ + y₂ = 0 (mod 2): 000, 001, 110, 111.
Suppose two runs give 001 and 111:

  • From 001: s₃ = 0.
  • From 111: s₁ + s₂ + s₃ = 0, so s₁ = s₂.
  • Since s ≠ 000, we get s = 110 ✓.

Why it matters: Simon's algorithm was the first exponential separation between quantum and classical query complexity, and it directly inspired Peter Shor to look for periods in number theory.

⚖️ The first algorithms

👍 The good
  • Small enough to calculate by hand
  • Show exactly how interference extracts global properties
  • Simon's algorithm gave the first exponential separation
👎 The tricky
  • Artificial problems with no direct practical use
  • Deutsch–Jozsa is easily matched by randomised classical algorithms
  • Depend on oracles that must be built as real circuits

🎒 Pack these 3 ideas

  1. Deutsch: 1 query instead of 2 to learn f(0) ⊕ f(1).
  2. Bernstein–Vazirani: find an n-bit secret in 1 query instead of n.
  3. Simon: the first exponential separation, and the direct inspiration for Shor.
