10.1The four-step recipe

Almost every quantum algorithm follows the same shape:

  1. Spread out: put the input register into a superposition of many possibilities (usually with Hadamard gates).
  2. Compute: apply the problem's function to all those possibilities at once, often writing the answer into phases.
  3. Interfere: apply a transformation (Hadamards, a Quantum Fourier Transform, or a "diffusion" step) that makes wrong answers cancel and right answers reinforce.
  4. Measure: read out a result that is now likely to be useful. Repeat a few times if needed.
💡 Lightbulb moment

Analogy: a pond. Drop many pebbles into a pond at carefully chosen spots and times. The ripples overlap. At most places they cancel into flat water, but at one special point they pile up into a big wave. A quantum algorithm is the art of choosing where to drop the pebbles so the big wave appears exactly at the answer.

10.2Quantum parallelism, and why it isn't enough

Applying H to each of n qubits creates an equal superposition of all 2ⁿ bit strings, using just n gates:

🧮 Pencil & paper

Example (2 qubits):

(H ⊗ H)|00⟩ = |+⟩|+⟩ = ½(|00⟩ + |01⟩ + |10⟩ + |11⟩)

Now feed this into a circuit U_f that computes some function f:

U_f : |x⟩|0⟩ → |x⟩|f(x)⟩

U_f applied to the superposition gives  (1/√2ⁿ) Σₓ |x⟩|f(x)⟩

In one run, the state contains every value f(x). This is quantum parallelism. But measuring gives just one random pair (x, f(x)), which is no better than computing f on a random input classically. The power only appears when we use interference to extract a global property of f (a period, a pattern, a hidden string) rather than individual values.

In quantum mechanics, 'control' and 'target' are a matter of perspective: a CNOT can change its own control qubit.

10.3Oracles and query complexity

Many algorithms are described using an oracle, a black box that computes f. We count how many times the algorithm must query the box. This makes speedups provable: for example, Grover's algorithm provably needs about √N queries where any classical algorithm needs about N. In real applications, the oracle must be built as an actual circuit, and its cost matters.

10.4Phase kickback: the key trick

If the oracle's output qubit is prepared in |−⟩, something surprising happens:

U_f |x⟩|−⟩ = (−1)^f(x) |x⟩|−⟩

The output qubit is unchanged, and the answer f(x) gets "kicked back" into the phase of the input. Phases are exactly what interference can work with.

🧮 Pencil & paper

Worked example: phase kickback with a CNOT. CNOT computes f(x) = x into the target. Use control |+⟩ and target |−⟩:

CNOT |+⟩|−⟩ = (1/√2)[ (−1)⁰|0⟩ + (−1)¹|1⟩ ] |−⟩ = |−⟩|−⟩

The control qubit changed (from |+⟩ to |−⟩) while the target did not! In quantum mechanics, "control" and "target" are a matter of perspective.

10.6The three catches every claimed speedup must survive

  1. Input: loading a large classical dataset into a quantum state can take as long as the classical computation itself. ("QRAM", hypothetical quantum memory hardware, would help, but nobody knows how to build it at scale.)
  2. Output: measurement gives samples, not the full state. If the answer is a huge vector, you can't read it all out.
  3. Structure: without exploitable structure, the best you can do is Grover's quadratic speedup.

Researchers have repeatedly shown that some claimed quantum speedups disappear once a classical algorithm gets the same input assumptions. This is called dequantisation; Ewin Tang's 2018 classical recommendation-system algorithm is the famous example.

⚖️ Quantum speedups

👍 The good
  • Exponential speedups for problems with hidden structure (periods, simulation)
  • Provable quadratic speedup for unstructured search
  • Oracle models make speedups provable
👎 The tricky
  • Loading big classical datasets can eat the whole speedup
  • You can only sample outputs, not read entire vectors
  • Many claimed speedups were later 'dequantised' (Tang, 2018)

🎒 Pack these 3 ideas

  1. Recipe: spread out → compute (into phases) → interfere → measure.
  2. Phase kickback writes f(x) into a phase, and phases are what interference works with.
  3. Every claimed speedup must survive three catches: input, output and structure.
