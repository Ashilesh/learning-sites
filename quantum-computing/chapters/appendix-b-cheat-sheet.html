Key identities

  • X² = Y² = Z² = H² = I
  • HXH = Z, HZH = X, HYH = −Y
  • XZ = −ZX (Pauli gates anticommute)
  • S² = Z, T² = S
  • SWAP = 3 CNOTs
  • CNOT|+⟩|−⟩ = |−⟩|−⟩ (phase kickback)
