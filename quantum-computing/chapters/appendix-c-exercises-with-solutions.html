CExercises with Solutions

⏱ 3 min0 sections🟡 Student✅ Completed

The hook20 exercises with solutions. Try each one before you peek. Every reveal earns XP.

⚡ In 30 seconds (no jargon, promise)

Grab a pencil. Each exercise uses ideas from the chapters. Work it out, then tap to reveal the solution.

Try each one before reading the solution.

1

A qubit is in the state (1/2)|0⟩ + (√3/2)|1⟩. What are the measurement probabilities?

👀 Reveal the solution +10 XP

Solution: P(0) = 1/4 = 25%, P(1) = 3/4 = 75%.

2

Is (|0⟩ + |1⟩)/2 a valid quantum state?

👀 Reveal the solution +10 XP

Solution: No. |1/2|² + |1/2|² = 1/2 ≠ 1. The normalised version is (|0⟩ + |1⟩)/√2.

3

Compute H|1⟩ and then HH|1⟩.

👀 Reveal the solution +10 XP

Solution: H|1⟩ = (|0⟩ − |1⟩)/√2 = |−⟩. Then H|−⟩ = |1⟩. Two Hadamards cancel, as always.

4

Show that XZ = −ZX by applying both to |0⟩.

👀 Reveal the solution +10 XP

Solution: XZ|0⟩ = X|0⟩ = |1⟩. ZX|0⟩ = Z|1⟩ = −|1⟩. They differ by a sign.

5

Is (|00⟩ + |01⟩ − |10⟩ − |11⟩)/2 entangled?

👀 Reveal the solution +10 XP

Solution: a·d = (1/2)(−1/2) = −1/4 and b·c = (1/2)(−1/2) = −1/4. Equal, so it's a product state: |−⟩ ⊗ |+⟩.

6

Is (|00⟩ + |01⟩ + |10⟩ − |11⟩)/2 entangled?

👀 Reveal the solution +10 XP

Solution: a·d = −1/4 but b·c = +1/4. Not equal, so it's entangled. (It's what you get by applying a CZ gate to |+⟩|+⟩.)

7

What does CNOT do to |+⟩|1⟩?

👀 Reveal the solution +10 XP

Solution: CNOT(|01⟩ + |11⟩)/√2 = (|01⟩ + |10⟩)/√2 = |Ψ⁺⟩, an entangled Bell state.

8

In the Bernstein–Vazirani problem with a 1,000-bit secret, how many queries does each approach need?

👀 Reveal the solution +10 XP

Solution: Classical: 1,000 (one per bit). Quantum: 1.

9

Use Shor's classical reduction to factor 35 with a = 2. (Hint: list powers of 2 mod 35.)

👀 Reveal the solution +10 XP

Solution: 2, 4, 8, 16, 32, 29, 23, 11, 22, 9, 18, 1, so r = 12. Then 2⁶ = 64 ≡ 29 (mod 35), which isn't −1 (34) ✓. gcd(28, 35) = 7 and gcd(30, 35) = 5. So 35 = 5 × 7.

10

How many Grover iterations are needed for one marked item among 2²⁰ ≈ 1 million items?

👀 Reveal the solution +10 XP

Solution: (π/4)√(2²⁰) = (π/4) × 1,024 ≈ 804.

11

A circuit has 500 gates, each with 99.5% fidelity. Roughly what's the probability that it runs error-free?

👀 Reveal the solution +10 XP

Solution: 0.995⁵⁰⁰ ≈ 0.082, so about 8%. This is why error correction is needed.

12

For a surface code with p/p_th = 0.2, how much does the logical error rate (relative to A) improve going from distance 5 to distance 11?

👀 Reveal the solution +10 XP

Solution: d = 5: 0.2³ = 0.008. d = 11: 0.2⁶ = 0.000064. That's an improvement of 125 times.

13

In BB84, if Eve intercepts and re-sends every photon, what error rate do Alice and Bob see in their sifted key?

👀 Reveal the solution +10 XP

Solution: About 25%. Eve picks the wrong basis half the time, and then Bob's result is wrong half of those times.

14

Data must stay secret for 10 years. Migration will take 5 years. A CRQC is expected in 12 years. Is the data at risk?

👀 Reveal the solution +10 XP

Solution: x + y = 15 > z = 12. Yes, so start migrating now.

15

In teleportation, Alice measures 11. Bob's qubit is α|1⟩ − β|0⟩. What must Bob do?

👀 Reveal the solution +10 XP

Solution: Apply X (giving α|0⟩ − β|1⟩), then Z (giving α|0⟩ + β|1⟩).

16

Why can't teleportation send information faster than light?

👀 Reveal the solution +10 XP

Solution: Without Alice's two classical bits, Bob's qubit is in one of four states with equal probability, which looks completely random to him. The classical bits travel no faster than light.

17

In superdense coding, which gate does Alice apply to send the message 10?

👀 Reveal the solution +10 XP

Solution: Z.

18

What's ⟨Z⟩ for the state Ry(π/2)|0⟩?

👀 Reveal the solution +10 XP

Solution: cos(π/2) = 0. The state is |+⟩, which is equally likely to give +1 or −1.

19

How much memory does a state-vector simulation of 40 qubits need at 16 bytes per amplitude?

👀 Reveal the solution +10 XP

Solution: 2⁴⁰ × 16 bytes = 16 TiB (about 17.6 TB). That's beyond a laptop and needs a large cluster.

20

(Challenge) Why doesn't Grover's algorithm let quantum computers solve NP-complete problems efficiently?

👀 Reveal the solution +10 XP

Solution: Grover's algorithm turns a 2ⁿ brute-force search into 2^(n/2), which is still exponential. And the BBBV theorem proves no quantum algorithm can do better for unstructured search. Efficient quantum algorithms need problem structure, which NP-complete problems aren't known to offer.
