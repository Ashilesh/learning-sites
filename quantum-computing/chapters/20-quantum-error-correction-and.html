20.1Why it seemed impossible

In the early 1990s, many physicists believed quantum error correction couldn't work:

  • No-cloning: you can't make backup copies of a qubit.
  • Measurement destroys: checking a qubit for errors would collapse its superposition.
  • Errors are continuous: a qubit can drift by any tiny angle, not just flip.

In 1995, Peter Shor found a way around all three, and Andrew Steane independently followed. The key idea: spread one qubit's information across many entangled physical qubits, and measure only collective properties (parities) that reveal errors but not the data.

20.2Warm-up: the classical repetition code

Encode 0 → 000 and 1 → 111. If one bit flips (000 → 010), majority vote recovers 0.

🧮 Pencil & paper

Worked example: if each bit independently flips with probability p = 1%, the code fails only if 2 or 3 bits flip:

P(fail) = 3p²(1−p) + p³ ≈ 3 × (0.01)² ≈ 0.0003  =  0.03%

33 times better than an unprotected bit, and it improves dramatically with more repetitions, as long as p is small enough. This "below a threshold, more redundancy helps" pattern is the core of all error correction.

20.3The quantum bit-flip code

Encode α|0⟩ + β|1⟩ → α|000⟩ + β|111⟩ using two CNOTs. This is not cloning (|ψ⟩|ψ⟩|ψ⟩ would be different). It's an entangled state where the information is shared.

To detect errors without destroying the superposition, we measure two parities, using helper (ancilla) qubits:

  • P₁₂: do qubits 1 and 2 agree? (the Z₁Z₂ stabilizer)
  • P₂₃: do qubits 2 and 3 agree? (the Z₂Z₃ stabilizer)
Syndrome (P₁₂, P₂₃)DiagnosisFix
(agree, agree)No errorNothing
(differ, agree)Qubit 1 flippedX on qubit 1
(differ, differ)Qubit 2 flippedX on qubit 2
(agree, differ)Qubit 3 flippedX on qubit 3
🧮 Pencil & paper

Worked example: a bit-flip hits qubit 2: α|000⟩ + β|111⟩ → α|010⟩ + β|101⟩.

  • P₁₂: in both 010 and 101, qubits 1 and 2 differ.
  • P₂₃: in both, qubits 2 and 3 differ.
  • Syndrome (differ, differ) → flip qubit 2 → back to α|000⟩ + β|111⟩ ✓

Crucially, the parity measurements give the same answer for both branches of the superposition, so they reveal where the error is without revealing anything about α or β. The superposition survives intact.

20.4Phase flips and Shor's 9-qubit code

Phase flips can be caught the same way, in the |+⟩/|−⟩ basis: |+⟩ → |+++⟩, |−⟩ → |−−−⟩. Shor's code nests the two codes (3 groups of 3 qubits) to protect against any single-qubit error, using 9 physical qubits per logical qubit.

The miracle of discretisation: a real error might be a tiny, continuous rotation. But when you measure the syndrome, the error is forced to "choose": either no error happened or a full X/Y/Z error happened, and the latter is corrected. Measurement turns analog errors into digital ones. This is why correcting just X and Z errors is enough to correct all errors.

20.5Code notation: [[n, k, d]]

A quantum code is labelled [[n, k, d]]: n physical qubits encode k logical qubits with distance d. It can correct up to ⌊(d−1)/2⌋ arbitrary errors.

Code[[n, k, d]]Notes
Shor code[[9, 1, 3]]First quantum code (1995)
Steane code[[7, 1, 3]]Elegant; many gates are "transversal" (easy to do fault-tolerantly)
Five-qubit code[[5, 1, 3]]Smallest code that corrects any single-qubit error
Surface code (rotated)[[d², 1, d]]Plus about d² measurement qubits. The industry workhorse
IBM "gross" code (bivariate bicycle qLDPC)[[144, 12, 12]]12 logical qubits in 144 data qubits (288 total with checks), roughly 10× more efficient than the surface code

20.6Stabilizer codes

Most practical codes are stabilizer codes (Gottesman, 1997). A code is defined by a set of multi-qubit Pauli operators (stabilizers) that leave every valid codeword unchanged, like Z₁Z₂ and Z₂Z₃ above. Measuring the stabilizers repeatedly produces a stream of syndrome bits. Any change in the syndrome flags an error. This formalism makes it possible to design, analyse and simulate codes efficiently (thanks to Gottesman–Knill, stabilizer circuits are classically simulable, so error-correction circuits can be tested at huge scales on ordinary computers with tools like Stim).

20.7The surface code

The surface code (descended from Kitaev's 1997 toric code) is the leading approach for superconducting chips:

   │   │   │   │   │
   D ─ Z ─ D ─ Z ─ D

Why it's popular:

  • Needs only a 2-D grid with nearest-neighbour connections.
  • Has a high threshold of about 1%: if physical error rates are below roughly 1%, making the code bigger makes logical errors exponentially rarer.

How logical error scales: p_logical ≈ A · (p / p_th)^((d+1)/2)

🧮 Pencil & paper

Worked example: physical error p = 0.1%, threshold p_th = 1%, so the ratio is 0.1.

3~1810⁻²

That's the deal error correction offers: trade hundreds to thousands of physical qubits for one excellent logical qubit.

Milestone: In December 2024, Google's Willow chip (105 qubits) ran surface codes at distances 3, 5 and 7. Each step up in distance cut the logical error rate by a factor of about 2.1, demonstrating "below-threshold" operation for the first time. The distance-7 logical qubit lasted more than twice as long as the best physical qubit on the chip.

20.8The threshold theorem

Proven independently by several groups in 1996–97 (Aharonov & Ben-Or; Kitaev; Knill, Laflamme & Zurek), the threshold theorem says:

If every physical component has an error rate below some threshold, then an arbitrarily long quantum computation can be performed reliably, with overhead that grows only polylogarithmically with the computation's size.

This is the theoretical foundation that makes large-scale quantum computing possible in principle.

20.9Decoders: the classical brain of a quantum computer

Syndrome bits must be interpreted ("decoded") into corrections in real time, fast enough to keep up with the hardware. For superconducting qubits that's about a microsecond per round, across millions of qubits eventually. Decoding algorithms include minimum-weight perfect matching (MWPM), union-find, belief propagation, and machine-learning decoders such as AlphaQubit (Google DeepMind, 2024). Decoding is a major engineering challenge and an active research field.

20.10Doing logic on encoded qubits

Storing qubits isn't enough; we need to compute on them without spreading errors.

  • Transversal gates: apply the same gate to each physical qubit in parallel. Errors can't spread within a code block. Great when available.
  • Lattice surgery: merge and split surface-code patches to perform entangling operations.
  • The catch (Eastin–Knill theorem): no code can perform a universal gate set transversally. Something has to be "hard".
  • Magic states: the usual solution. Prepare special "magic" states (like T|+⟩), purify them through magic state distillation (Bravyi & Kitaev, 2005), then consume them to perform T gates via teleportation. Distillation "factories" can take up a large fraction of a fault-tolerant chip. Newer techniques such as magic state cultivation (Gidney, Shutty and Jones, 2024) reduce the cost substantially.

20.13The overhead problem and the "megaquop" milestone

Fault tolerance is expensive: today's estimates for useful algorithms call for hundreds of thousands to millions of physical qubits. The field now talks about intermediate goals, such as the "megaquop" machine (John Preskill's term), meaning a computer that can reliably run about a million logical operations. That's beyond classical simulation but well short of breaking RSA. Many companies target such machines for the late 2020s (Chapter 29).

⚖️ Quantum error correction

👍 The good
  • Makes arbitrarily long computations possible in principle
  • Measurement 'digitises' continuous errors into X and Z flips
  • Logical qubits now outlive the best physical ones
👎 The tricky
  • Hundreds to thousands of physical qubits per logical qubit
  • Real-time decoding at microsecond speeds is hard
  • T gates need costly magic-state factories

🎒 Pack these 3 ideas

  1. Parity checks (stabilizers) find errors without learning α or β.
  2. Surface code: about 1% threshold, with p_L ≈ A(p/p_th)^((d+1)/2).
  3. Google Willow (2024): each step up in code distance cut logical errors by about 2.1×.
