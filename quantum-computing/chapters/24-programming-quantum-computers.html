24.2Build your own quantum simulator in ~70 lines of Python

The best way to really understand quantum computing is to simulate it yourself. This simulator uses only NumPy (pip install numpy) and applies exactly the math from Chapters 5 to 7: states are vectors, gates are matrices, multi-qubit gates are built with tensor products, and probabilities come from the Born rule.

Python
import numpy as np

# ---------- Basic single-qubit gates (2x2 unitary matrices) ----------
I = np.eye(2, dtype=complex)
X = np.array([[0, 1], [1, 0]], dtype=complex)
Y = np.array([[0, -1j], [1j, 0]], dtype=complex)
Z = np.array([[1, 0], [0, -1]], dtype=complex)
H = np.array([[1, 1], [1, -1]], dtype=complex) / np.sqrt(2)
S = np.array([[1, 0], [0, 1j]], dtype=complex)
T = np.array([[1, 0], [0, np.exp(1j * np.pi / 4)]], dtype=complex)

def RY(theta):
    c, s = np.cos(theta / 2), np.sin(theta / 2)
    return np.array([[c, -s], [s, c]], dtype=complex)

P0 = np.array([[1, 0], [0, 0]], dtype=complex)   # |0><0|  projector
P1 = np.array([[0, 0], [0, 1]], dtype=complex)   # |1><1|  projector


def kron_all(matrices):
    """Tensor product of a list of matrices: M0 ⊗ M1 ⊗ ... ⊗ Mn-1."""
    result = matrices[0]
    for m in matrices[1:]:
        result = np.kron(result, m)
    return result


class Circuit:
    """A tiny state-vector simulator.
    Convention: qubit 0 is the LEFTMOST character of a bit string like '01'."""

    def __init__(self, n_qubits):
        self.n = n_qubits
        self.state = np.zeros(2 ** n_qubits, dtype=complex)
        self.state[0] = 1.0                      # start in |00...0>

    def gate(self, U, target):
        """Apply a single-qubit gate U to one qubit (identity on the rest)."""
        ops = [U if q == target else I for q in range(self.n)]
        self.state = kron_all(ops) @ self.state
        return self

    def controlled(self, U, control, target):
        """Controlled-U = |0><0| ⊗ I  +  |1><1| ⊗ U  (on the chosen qubits)."""
        if_0 = [P0 if q == control else I for q in range(self.n)]
        if_1 = [P1 if q == control else (U if q == target else I)
                for q in range(self.n)]
        self.state = (kron_all(if_0) + kron_all(if_1)) @ self.state
        return self

    def cnot(self, control, target):
        return self.controlled(X, control, target)

    def cz(self, control, target):
        return self.controlled(Z, control, target)

    def probabilities(self):
        """Born rule: probability = |amplitude|^2 for each basis state."""
        probs = np.abs(self.state) ** 2
        return {format(i, f"0{self.n}b"): round(float(p), 4)
                for i, p in enumerate(probs) if p > 1e-12}

    def measure(self, shots=1000, seed=None):
        """Sample measurement outcomes, like running the circuit many times."""
        rng = np.random.default_rng(seed)
        probs = np.abs(self.state) ** 2
        outcomes = rng.choice(2 ** self.n, size=shots, p=probs / probs.sum())
        counts = {}
        for o in outcomes:
            key = format(o, f"0{self.n}b")
            counts[key] = counts.get(key, 0) + 1
        return dict(sorted(counts.items()))

Now let's use it to reproduce the worked examples from this guide:

Python
# 1) Interference: H then H returns |0> with certainty
c = Circuit(1).gate(H, 0)
print("After one H :", c.probabilities())
c.gate(H, 0)
print("After two Hs:", c.probabilities())

# 2) Bell state (|00> + |11>)/sqrt(2)
bell = Circuit(2).gate(H, 0).cnot(0, 1)
print("Bell amplitudes:", np.round(bell.state, 3))
print("Bell, 1000 shots:", bell.measure(1000, seed=7))

# 3) Grover search on 4 items, marked item = |11>
g = Circuit(2).gate(H, 0).gate(H, 1)
g.cz(0, 1)                                   # oracle: flip sign of |11>
for q in (0, 1): g.gate(H, q).gate(X, q)     # diffusion operator ...
g.cz(0, 1)
for q in (0, 1): g.gate(X, q).gate(H, q)
print("Grover result:", g.probabilities())

# 4) Bernstein-Vazirani: find hidden string s = 101 in ONE query
s = "101"
n = len(s)
bv = Circuit(n + 1)                          # last qubit is the helper
bv.gate(X, n).gate(H, n)                     # helper in |->
for q in range(n): bv.gate(H, q)
for q, bit in enumerate(s):                  # oracle f(x) = s·x mod 2
    if bit == "1":
        bv.cnot(q, n)
for q in range(n): bv.gate(H, q)
probs = bv.probabilities()
print("Bernstein-Vazirani:", probs)          # input qubits read 101

# 5) A qubit with 75% chance of 0: Ry(pi/3)|0>
print("Ry(pi/3):", Circuit(1).gate(RY(np.pi / 3), 0).probabilities())

Output:

After one H : {'0': 0.5, '1': 0.5}
After two Hs: {'0': 1.0}
Bell amplitudes: [0.707+0.j 0.   +0.j 0.   +0.j 0.707+0.j]
Bell, 1000 shots: {'00': 502, '11': 498}
Grover result: {'11': 1.0}
Bernstein-Vazirani: {'1010': 0.5, '1011': 0.5}
Ry(pi/3): {'0': 0.75, '1': 0.25}

Every line matches a hand calculation from earlier chapters:

  • Two Hadamards give |0⟩ with certainty: interference (Chapter 6.5).
  • The Bell state only ever gives 00 or 11 (Chapter 7.4).
  • Grover finds the marked item 11 with 100% probability in one iteration (Chapter 14.3).
  • Bernstein–Vazirani reveals the secret 101 in one query. The fourth character is the helper qubit, which stays in |−⟩, giving 50/50 (Chapter 11.3).
  • Ry(π/3) makes the 75/25 state (Chapter 6.7).
💡 Lightbulb moment

Why this simulator can't scale: the kron_all function builds a 2ⁿ × 2ⁿ matrix. At 15 qubits that's already about a billion entries. Real simulators apply gates without building full matrices, but they still need 2ⁿ amplitudes. That's the exponential wall from Chapter 1, and the reason we need real quantum hardware.

24.3Qiskit (IBM)

Install: pip install qiskit qiskit-aer

A Bell state on a local simulator:

Python
from qiskit import QuantumCircuit, transpile
from qiskit_aer import AerSimulator

qc = QuantumCircuit(2, 2)        # 2 qubits, 2 classical bits
qc.h(0)                          # superposition on qubit 0
qc.cx(0, 1)                      # entangle: CNOT with control 0, target 1
qc.measure([0, 1], [0, 1])

print(qc.draw())                 # ASCII drawing of the circuit

sim = AerSimulator()
result = sim.run(transpile(qc, sim), shots=1000).result()
print(result.get_counts())       # e.g. {'00': 508, '11': 492}

Inspecting the exact state (no measurement):

Python
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

bell = QuantumCircuit(2)
bell.h(0)
bell.cx(0, 1)
print(Statevector(bell))         # amplitudes ≈ [0.707, 0, 0, 0.707]

Grover's search on 4 items (marked item 11):

Python
from qiskit import QuantumCircuit

grover = QuantumCircuit(2, 2)
grover.h([0, 1])                 # equal superposition
grover.cz(0, 1)                  # oracle: flip the sign of |11⟩
grover.h([0, 1])                 # diffusion: reflect about the mean
grover.x([0, 1])
grover.cz(0, 1)
grover.x([0, 1])
grover.h([0, 1])
grover.measure([0, 1], [0, 1])
# Running this gives '11' every time on an ideal simulator.

Running on real IBM hardware (requires a free IBM Quantum account and pip install qiskit-ibm-runtime; save your API credentials first, following IBM's documentation):

Python
from qiskit_ibm_runtime import QiskitRuntimeService, SamplerV2 as Sampler
from qiskit.transpiler import generate_preset_pass_manager

service = QiskitRuntimeService()
backend = service.least_busy(operational=True, simulator=False)

pm = generate_preset_pass_manager(backend=backend, optimization_level=1)
isa_circuit = pm.run(qc)         # translate to the chip's native gates and layout

job = Sampler(mode=backend).run([isa_circuit], shots=1000)
counts = job.result()[0].data.c.get_counts()
print(counts)                    # mostly '00' and '11', plus a few errors
⚠️ Heads up

Bit order: Qiskit prints bit strings with qubit 0 on the right. So '01' means qubit 0 = 1 and qubit 1 = 0. Our NumPy simulator and most textbooks put qubit 0 on the left.

24.4Cirq (Google)

Install: pip install cirq

Python
import cirq

q0, q1 = cirq.LineQubit.range(2)
circuit = cirq.Circuit(
    cirq.H(q0),
    cirq.CNOT(q0, q1),
    cirq.measure(q0, q1, key="m"),
)
print(circuit)

result = cirq.Simulator().run(circuit, repetitions=1000)
print(result.histogram(key="m"))  # Counter({0: ~500, 3: ~500})  (0 = '00', 3 = '11')

24.5PennyLane (Xanadu): a tiny variational algorithm

Install: pip install pennylane

This is the toy VQE from Chapter 16.2: find the angle θ that minimises ⟨Z⟩ for the state Ry(θ)|0⟩.

Python
import pennylane as qml
from pennylane import numpy as np

dev = qml.device("default.qubit", wires=1)

@qml.qnode(dev)
def energy(theta):
    qml.RY(theta, wires=0)
    return qml.expval(qml.PauliZ(0))     # the "energy" ⟨Z⟩ = cos θ

opt = qml.GradientDescentOptimizer(stepsize=0.4)
theta = np.array(0.1, requires_grad=True)
for step in range(60):
    theta = opt.step(energy, theta)

print(theta, energy(theta))   # θ → π ≈ 3.14159, energy → −1

PennyLane computes gradients of quantum circuits automatically, using the parameter-shift rule on hardware.

@cudaq.kernel
def bell():
    q = cudaq.qvector(2)

24.8OpenQASM 3: the "assembly language" of quantum circuits

OpenQASM 3
OPENQASM 3.0;
include "stdgates.inc";

qubit[2] q;
bit[2] c;

h q[0];
cx q[0], q[1];
c = measure q;

Most SDKs can import and export OpenQASM, so it works as a common exchange format.

24.9Practical tips for quantum programmers

  1. Start on a simulator. Debug with exact state vectors before touching hardware.
  2. Count two-qubit gates and depth. They dominate errors on real machines. Check the circuit after transpilation.
  3. Mind the bit ordering of your SDK.
  4. Use enough shots, and remember statistical error scales as 1/√shots.
  5. Add realistic noise models in simulation to predict hardware behaviour.
  6. Exploit hardware connectivity: choose qubit layouts that minimise SWAPs.
  7. Use error mitigation options (readout correction, ZNE, dynamical decoupling) on today's hardware.
  8. Read the docs for your exact version. APIs move quickly.
