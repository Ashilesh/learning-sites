# Tech Explainers

Hands-on, visual guides to how computers and the internet work, published with GitHub Pages.

- Home page: `index.html` (generated from `assets/sites.js`)
- Sub-sites: one folder per topic (`PQC/`, `QUIC/`, …)

**Add a new site:** drop its folder at the repo root, then add one entry to `window.SITES` in
[`assets/sites.js`](assets/sites.js). See [`CLAUDE.md`](CLAUDE.md) for the full checklist.

**Publish:** push to GitHub → Settings → Pages → Deploy from branch → `main` / root.
